How to Send a Phone Note

Follow these steps in order to log a telephone call and route a message to the correct provider — for example, when a patient requests a care transfer.

Phase 1

Find the Encounter

1

Look up the patient's chart in the EHR.

2

Next to the call center icon, select the provider (MD or NP/PA) the patient currently sees.

3

Check whether the patient already has an encounter for today's date.

If there isn't one yet, click New to create one.
4

Once the encounter is created, click Telephone Call.

Phase 2

Log the Call Details

5

In the Communication section, click Outgoing Call.

6

Fill in the call fields:

Contact Type → select Incoming Call
Urgency → select When Available
Spoke With → select Patient if you spoke to them directly. If not, note who you actually spoke with instead.
Don't touch these: leave the date and time of the call exactly as they are — never modify them.
Phase 3

Write the Message

7

In the comment box, write the note for the provider the patient wants to transfer to. Pick the template that matches the patient's reason:

Reason: Relocation — copy this
Good morning, patient would like to transfer his/her care to you due to location. Is this ok?
Reason: Personal Preference — copy this
Good morning, patient would like to transfer his/her care to you per personal preference. Is this ok?
Reason: Referral — copy this
Good morning, patient would like to transfer his/her care to you per referral from Dr. [referring provider's name]. Is this ok?
Swap in the specific detail each template needs — the referring provider's name for a referral, for example — before sending.
8

Skip all other tabs. Click Send and Close.

Careful — there are two "Send and Close" buttons. Make sure you click the first one, not the second.
Phase 4

Route It to the Provider

9

In the Available Fields box, type the last name and first name of the provider the patient wants to transfer to.

10

Select that provider's name to add them as the task recipient, then click OK.

You'll be taken back to the Telephone Call window, where you'll now see the message you just sent in the communication field.
Phase 5

Follow Up

11

Once the provider responds, check for it by clicking the inbox icon at the top of the EHR.

12

Remember: call the patient back as soon as you receive the provider's response.

Quick Recap

1Find the patient's encounter (or create one for today).
2Open Telephone Call → Outgoing Call.
3Set Contact Type, Urgency, and Spoke With — never touch date/time.
4Write the transfer message in the comment box.
5Send and Close, then add the receiving provider as recipient.
6Watch the inbox for their response, then call the patient back.
